# Claude Design 依頼プロンプト（図版の作成・差し替え）

`index.html` に含まれる2つの図版は暫定版です。本ファイルのプロンプトAとBをClaude Designに渡して作り込み、末尾の手順で差し替えます。

参考画像として、KDDI「ストリーミングサービス概要図」（左＝お客様の枠囲みグループ／中央＝プラットフォームの円柱／右＝エンドユーザの楕円／太い block arrow で左右をつなぐ構成）を添付してください。**この図の構造の簡素さ・情報量の少なさを狙いとします。装飾やクリップアートは不要です。**

---

## 共通の制約（プロンプトA・Bのどちらにも適用）

```
【出力形式】
- インラインSVG 1つ。ラスタ画像・外部ファイル・外部フォント読み込みは不可（配信先のCSPでブロックされます）
- viewBox を指定し、width="100%" height="auto" でスケールすること
- テキストは <text> で出力すること（パス化しない。検索・翻訳・スクリーンリーダーのため）
- <title> と <desc> を付けること

【配色】必ず CSS 変数を参照し、リテラルの色は使わないこと（ライト／ダーク両テーマに追従させるため）
  var(--ink)        本文テキスト      #0F1926 / dark #EAF0F7
  var(--ink-2)      副次テキスト      #33414F / dark #C2CFDD
  var(--muted)      補足テキスト      #5D6B7C / dark #93A3B5
  var(--faint)      注記テキスト      #8695A6 / dark #718295
  var(--surface)    面（箱の地）      #FFFFFF / dark #121C29
  var(--surface-2)  面（ラベルの地）  #EDF1F6 / dark #182434
  var(--rule)       罫線              #D3DBE5 / dark #2A3A4C
  var(--navy)       本体（濃紺の塊）  #0A2540 / dark #050D17
  var(--blue)       防御・接続        #0057B8 / dark #5EA8FF
  var(--blue-wash)  防御の淡い地      #E7EFF9 / dark #132538
  var(--crimson)    攻撃・侵入        #AE0F22 / dark #FF8290
  var(--amber)      波及・警告        #8A5A00 / dark #E8B45C
  ※ 濃紺の塊（var(--navy)）の上に置く文字だけは、両テーマで濃紺のままのため #FFFFFF / #CFE0F0 等のリテラル可

【フォント】font-family には var(--f-body)（和文サンセリフ）を指定。見出しのみ var(--f-display)（明朝）可

【意味の割り当て】色は装飾ではなく意味を持たせること
  赤（crimson）= 攻撃側・侵入経路 ／ 濃紺（navy）= 自社の本体 ／ 青（blue）= 接続・防御 ／ 琥珀（amber）= 外部への波及

【トーン】メガバンクのCIO・CISO向けの技術白書。厳格・平板・情報密度は低め。
  避けるもの：グラデーション、ドロップシャドウ、絵文字、アイコンイラスト、角丸の多用、3D表現、アニメーション
```

## プロンプトA：フロー図「メガバンク固有の3条件 ── 入口・本体・出口」

```
メガバンクのサイバーセキュリティ白書に載せる、左から右へ流れる構造図をインラインSVGで作成してください。
「入口は本体の外に広がっている／本体は大きく止められない／出口は社会につながっている」という3点が、
図を見ただけで伝わることが唯一の目的です。

■ 全体構成（左→右）
  ゾーン①「入口：グループ・委託先」（左）
  → 赤い太矢印「侵入」×2 →
  ゾーン②「本体：止められない」（中央・濃紺の円柱）
  → 琥珀の矢印「波及」→
  対外接続系（縦長の柱・青系）を通過し
  → ゾーン③「出口：自社の外へ」（右・楕円ノード4つ）

■ ゾーン①：枠囲みの箱を2つ、縦に並べる。各箱の上辺に小さなラベルタグを付ける
  箱1 タグ「グループ会社」
      ・信託・証券・カード・リース
      ・海外拠点・現地法人
      ・（注記）業務システムで本体と連結
  箱2 タグ「委託先・外部ベンダー」
      ・開発・運用の委託先
      ・保守・データセンター事業者
      ・（注記）1,800システム中1,100が外部管理

■ ゾーン②：濃紺の円柱（上下に楕円、上面はわずかに明るく）。中の文字は白系
  見出し「勘定系」
  ・自前保有・数千万行規模
  ・COBOL中心
  ・「触るのが怖い」コード
  （区切り線）
  ・24時間365日
  ・停止できない  ← ここだけ琥珀色で強調

■ 対外接続系：縦に長い柱（楕円または角丸の縦帯）。青系の淡い地に青の輪郭
  見出し「対外接続系」
  ・全銀システム
  ・日銀ネット
  ・SWIFT・CAFIS
  ※ この柱は「被害が外に出ていく通路」であることが分かるよう、
     本体からの矢印がここを通って右へ抜ける構成にしてください

■ ゾーン③：楕円ノードを4つ縦に並べる（白地・青の輪郭）
  ・取引先金融機関
  ・企業・個人の決済
  ・証券・清算インフラ
  ・社会機能・生活基盤

■ 各ゾーンの上端に、小さな色付き四角＋見出しを置く
  ■（赤）① 入口：グループ・委託先
  ■（青）② 本体：止められない
  ■（琥珀）③ 出口：自社の外へ

■ サイズ：横長。viewBox は幅1000前後、高さ420前後を目安（内容に応じて調整可）
```

## プロンプトB：5層システム構成図

```
メガバンクの情報システムを5層＋2縦断で表した俯瞰図を、インラインSVGで作成してください。
層を上から下へ積み、「①と②のあいだに最大の隙間がある」ことが視覚的に際立つ構成にしてください。

■ 積む順序（上から）
  ① チャネル層（フロント）
     営業店端末／ATM・CD／コンタクトセンター／Web・アプリ／オープンAPI・BaaS／
     法人向けEB・CMS／代理店端末／外部プラットフォーム連携
     → 右端に赤いチップ「リスク01」

  ★【最大の隙間】← 赤い破線の帯で、層と層のあいだに挟む。この図の主役
     FEP・MQ・API GW・ESB（最大のレガシー債務）／
     テレワーク用VPN・リモート接続基盤／グループ会社・委託先との連携口

  ② 業務系（周辺系）
     融資・審査／外為／投信・窓販／法人業務／CRM／ワークフロー・稟議／グループ横断の顧客情報連携

  ③ コア系（勘定系）★ミッションクリティカル ← 左端の縦罫を赤にして他と区別
     元帳（口座・契約）／リアルタイム取引（OLTP）／日次・月次バッチ／資金決済・付替／手数料・利息計算
     → 右端に赤いチップ「リスク02」

  ④ 対外接続系 ← 左端の縦罫を琥珀に
     全銀システム／日銀ネット／CAFIS／ANSER／SWIFT／取引所／JASDEC・JSCC／国際ブランドNW／海外拠点・現地決済網
     → 右端に赤いチップ「リスク03」

  ⑤ 情報系
     DWH・データレイク・MDM／リスク・ALM／規制報告／AML・不正検知／BI／生成AI基盤

■ 最下部に、横並びで2つの帯（層を縦断するもの）
  縦断A：共通基盤 … ID・統合認証／統合監視・ジョブ／帳票／セキュリティ／BCP・DR
  縦断B：リスク＆コンプライアンス … FISC安全対策基準／金融分野サイバーセキュリティGL／監督指針・内部統制

■ 各層の左側に、層番号と英字ラベルを固定幅で置く
  ① チャネル層 / FRONT      ② 業務系 / BUSINESS    ③ コア系（勘定系）/ MISSION CRITICAL
  ④ 対外接続系 / EXTERNAL LINKS                     ⑤ 情報系 / DATA

■ 図の下に注記
  ※ リスク04（グループ会社・委託先経由の侵入）とリスク05（修復のボトルネック）は
    特定の層に閉じず、図全体を横断して発生する。

■ サイズ：横長。viewBox は幅1000前後、高さは内容に応じて（600〜760程度）
```

## 差し替え手順

生成されたSVGを受け取ったら、以下をClaude Codeに渡してください。

```
SBOAI_LP_MUFG_MOC リポジトリの index.html の図版を差し替えてください。

【A：フロー図】
<figure class="flowfig"> 〜 </figure> の中にある <svg> 〜 </svg> を、以下のSVGに丸ごと置き換える。
<figure> と <p class="flowfig__cap"> と <div class="flowfig__scroll"> は残すこと。

（ここに生成されたSVGを貼り付け）

【B：5層構成図】
<div class="arch"> 〜 </div> のブロック全体を、以下のSVGに置き換える。
直後の <p class="archnote"> は残すこと。
差し替え後は、不要になった .layer / .gap / .spans 系のCSSを削除してよい。

（ここに生成されたSVGを貼り付け）

【差し替え後の確認】
1. 色がすべて var(--...) 参照になっていること（リテラルの色が残っていないか）
   ただし濃紺の塊の上に置く白系文字のリテラルは可
2. 外部リソースの読み込みが増えていないこと（Google Fonts以外は不可）
3. タグの閉じ忘れがないこと
4. ライト／ダーク両テーマで文字が背景に溶けていないこと
5. 横幅の狭い画面で、図が自身のコンテナ内で横スクロールし、ページ全体は横スクロールしないこと
   （.flowfig__scroll は overflow-x:auto、内側のsvgは min-width:820px を指定済み）
```
