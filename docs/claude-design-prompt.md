# Claude Design 依頼プロンプト ── 構成図の視覚化

## 前提：6業界で同じ図を使い回している

本リポジトリは、メガバンク／電力／化学／航空／物流／情報通信の**6業界版**を `build.py` から生成しています。各版の第2章にある構成図は、**同一のSVGテンプレートに業界別のラベルを流し込んだもの**です。

したがって依頼するのは、6枚を個別に作ることではなく、**1つのテンプレートを設計し直すこと**です。差し込まれる文字列は業界ごとに変わるため、文字数の増減に耐える設計にしてください。

参考画像として、KDDI「ストリーミングサービス概要図」（左＝お客様の枠囲みグループ／中央＝プラットフォームの円柱／右＝エンドユーザの楕円／太い block arrow で左右をつなぐ構成）を添付してください。**この図の構造の簡素さ・情報量の少なさを狙いとします。**

---

## 図が担う役割

左から右へ、3つの工程を1本の流れとして見せる。

```
① アクセス経路（侵入口）      ② 感染拡大と重要資産      ③ イグレスと波及先
   3つの箱          →→→       濃紺の円柱        →→→     縦の柱 → 楕円4つ
```

読み手に伝えたいのは次の一点です。

> 入口は自社の外にあり、入られた先には全部つながっていて、出口は自社では塞ぎきれない。

## テンプレートの構造（差し込み位置）

以下の `{{...}}` が業界ごとに差し替わります。**文字数は業界により最大1.5倍程度ぶれます。**

### ゾーン①：侵入口（左）— 枠囲みの箱を3つ縦に並べる
各箱は3行構成。
```
{{見出し}}        例）委託先・取引先 ／ 保守事業者・委託先 ／ 卸先・MVNO・代理店
{{説明}}          例）保守・運用の外部アカウント
{{補足}}          例）IPA 10大脅威 2026 ／ 2位
```
3箱それぞれから、中央へ赤い太矢印（ラベル「侵入」）。

### ゾーン②：感染拡大と重要資産（中央）— 濃紺の円柱
上から順に、区切り線を挟んで3ブロック。行数は業界により 8〜10 行で変動します。
```
{{見出し}}（大きく）   例）クラウンジュエル ／ 制御系（OT）／ コア系（基盤系）
{{中身の行}} × 2〜3
──────────
Tier 0 ／ 特権ID       ← ここだけ琥珀色で強調（全業界共通）
{{中身の行}} × 1〜2
──────────
{{中身の行}}
{{結び}}（小さく）     例）奪われた時点で全てが開く
```

### 対外の柱（中央右）— 縦長の柱
```
イグレス（出口）        ← 全業界共通
HTTPS / SMTP・IMAP / FTP・SFTP / DNS   ← 全業界共通
```
中央の円柱からこの柱へ、琥珀の矢印（ラベル「流出」）。柱を通って右へ抜ける構成。

### ゾーン③：波及先（右）— 楕円ノードを4つ縦に並べる
```
{{波及先}} × 4    例）取引先金融機関／需要家・広域停電／欠航・遅延／委託元ECの通販停止
```

### 各ゾーンの上端
小さな色付き四角＋見出し。全業界共通。
```
■（赤）  ① アクセス経路（侵入口）
■（青）  ② 感染拡大と重要資産
■（琥珀）③ イグレスと波及先
```

## 制約

```
【出力形式】
- インラインSVG 1つ。ラスタ画像・外部ファイル・外部フォント読み込みは不可
  （配信先のCSPでブロックされます）
- viewBox を指定し、width="100%" height="auto" でスケールすること
- テキストは <text> で出力すること（パス化しない。検索・翻訳・読み上げのため）
- <title> と <desc> を付けること
- 文字数の増減に耐えること。中央の円柱は 8〜10 行、箱の見出しは 6〜12 文字で変動する

【配色】必ず CSS 変数を参照し、リテラルの色は使わないこと（ライト／ダーク両テーマに追従）
  var(--ink)          本文テキスト      #0F1926 / dark #EAF0F7
  var(--ink-2)        副次テキスト      #33414F / dark #C2CFDD
  var(--muted)        補足テキスト      #5D6B7C / dark #93A3B5
  var(--faint)        注記テキスト      #8695A6 / dark #718295
  var(--surface)      面（箱の地）      #FFFFFF / dark #121C29
  var(--surface-2)    面（ラベルの地）  #EDF1F6 / dark #182434
  var(--rule)         罫線              #D3DBE5 / dark #2A3A4C
  var(--navy)         中央の円柱        #0A2540 / dark #050D17
  var(--blue)         防御・接続        #0057B8 / dark #5EA8FF
  var(--blue-wash)    防御の淡地        #E7EFF9 / dark #132538
  var(--crimson)      侵入              #AE0F22 / dark #FF8290
  var(--crimson-wash) 侵入の淡地        #FBEAEC / dark #2C1519
  var(--amber)        流出              #8A5A00 / dark #E8B45C
  var(--amber-wash)   流出の淡地        #FBF1DE / dark #2A2213
  ※ var(--navy) の円柱の上に置く文字だけは、両テーマで濃紺のままのため
    #FFFFFF / #CFE0F0 / #F0B95C 等のリテラル可

【フォント】font-family には var(--f-body)。見出しのみ var(--f-display) 可

【意味の割り当て】色は装飾ではなく意味を持たせること
  赤 ＝ 侵入 ／ 濃紺 ＝ 自社の中核 ／ 青 ＝ 接続・防御 ／ 琥珀 ＝ 外部への流出

【トーン】CIO・CISO向けの技術白書。厳格・平板。
  避けるもの：グラデーション、ドロップシャドウ、絵文字、アイコンイラスト、
  3D表現、アニメーション、角丸の多用
```

## 差し替え手順

生成されたSVGを受け取ったら、以下をClaude Codeに渡してください。**6ファイルを個別に編集するのではなく、`build.py` の `diagram()` 関数を書き換えて再生成します。**

```
SBOAI_LP_MUFG_MOC リポジトリの構成図を差し替えてください。

build.py の diagram() 関数が生成しているSVGを、以下の設計に置き換える。
業界別データ（INDUSTRIES の各 diag）の差し込み位置は変えないこと。

（ここに生成されたSVGを貼り付け。差し込み箇所は {{...}} で示す）

置き換えたら python3 build.py を実行し、6ファイルすべてを再生成する。

【差し替え後の確認】
1. 6業界すべてで文字がはみ出していないこと
   （中央の円柱の行数と、箱の見出しの文字数が業界ごとに異なる）
2. 色がすべて var(--...) 参照になっていること
   ただし濃紺の円柱の上に置く文字のリテラルは可
3. 外部リソースの読み込みが増えていないこと（Google Fonts以外は不可）
4. タグの閉じ忘れがないこと
5. ライト／ダーク両テーマで文字が背景に溶けていないこと
6. 狭い画面で、図が自身のコンテナ内で横スクロールし、
   ページ全体は横スクロールしないこと
   （.flowfig__scroll は overflow-x:auto。内側のsvgの min-width を実寸に合わせる）
```
