# Claude Design 依頼プロンプト ── セキュリティカオスマップの視覚化

**キーワードの中身は確定済み**です（`index.html` 第2章の `.cmap` ブロック、93項目）。Claude Designに依頼するのは、この内容を**より圧のある見た目に作り替えること**です。

到達すべき読後感は次の一文。

> こんなにリスクがあるのか。自社ではハンドルしきれない。一旦PaaSに任せよう。

## 前提

**読み手**：年商300億円以上の企業のCIO・CISO・リスク管理責任者。ただし2000億円以下の層には専門用語が通じない。

**掲載面**：LP（スマートフォン閲覧を含む）。駅広告からの流入を想定しており、じっくり読む場面ではない。

**現状の実装**：3カラム（侵入口／内部システム／波及先）に、サブグループ別のキーワードチップを敷き詰めたHTML。93項目のうち42項目に「直近1年に国内事例あり」の●印と、事案名のツールチップが付いている。

**依頼内容**：この構造と文言は変えずに、視覚的な密度と圧を上げる。

---

## 作り替えの方針

```
1. 量が一目で伝わること
   93項目という数そのものが訴求になる。整然と並べるより、
   「全部つぶすのは無理だ」と感じる密度を優先する。

2. 3セグメントの役割差を色で分ける
   侵入口 ＝ 赤系（攻撃が入ってくる側）
   内部システム ＝ 濃紺／青系（守るべき側）
   波及先 ＝ 琥珀系（外へ出ていく側）

3. 強弱をつける
   IPA 10大脅威 2026 の上位に該当する項目、および直近1年で
   実際に使われた侵入経路は、他より強く見せる。
   逆に、それ以外は意図的に弱く小さく置いてよい。

4. ●印（直近1年の国内事例あり）を目立たせる
   「これは想定ではなく、実際に起きている」ことが伝わる印にする。

5. 感染が広がる順序だけは、順序として見せる
   従業員端末 → 情シス権限 → 特権ID → 重要データ
   ここだけは並列ではなく、進行として読ませたい。
```

## 制約

```
【出力形式】
- インラインSVG または HTML/CSS のいずれか。ラスタ画像・外部ファイル・
  外部フォント読み込みは不可（配信先のCSPでブロックされます）
- SVGの場合：viewBox を指定し、width="100%" height="auto" でスケールすること。
  テキストは <text> で出力（パス化しない）。<title> と <desc> を付ける
- HTMLの場合：レスポンシブに（広い画面で3カラム、狭い画面で縦積み）

【配色】必ず CSS 変数を参照し、リテラルの色は使わないこと
  var(--ink)          本文テキスト        #0F1926 / dark #EAF0F7
  var(--ink-2)        副次テキスト        #33414F / dark #C2CFDD
  var(--muted)        補足テキスト        #5D6B7C / dark #93A3B5
  var(--faint)        注記テキスト        #8695A6 / dark #718295
  var(--surface)      面（カードの地）    #FFFFFF / dark #121C29
  var(--surface-2)    面（チップの地）    #EDF1F6 / dark #182434
  var(--rule)         罫線                #D3DBE5 / dark #2A3A4C
  var(--navy)         濃紺の塊            #0A2540 / dark #050D17
  var(--blue)         内部システム        #0057B8 / dark #5EA8FF
  var(--blue-wash)    内部システムの淡地  #E7EFF9 / dark #132538
  var(--crimson)      侵入口              #AE0F22 / dark #FF8290
  var(--crimson-wash) 侵入口の淡地        #FBEAEC / dark #2C1519
  var(--amber)        波及先              #8A5A00 / dark #E8B45C
  var(--amber-wash)   波及先の淡地        #FBF1DE / dark #2A2213
  ※ var(--navy) の塊の上に置く文字だけは、両テーマで濃紺のままのため
    #FFFFFF / #CFE0F0 等のリテラル可

【フォント】font-family には var(--f-body)。見出しのみ var(--f-display) 可

【トーン】厳格・平板。避けるもの：グラデーション、ドロップシャドウ、絵文字、
  アイコンイラスト、3D表現、アニメーション、角丸の多用
```

## 差し替え手順

生成物を受け取ったら、以下をClaude Codeに渡してください。

```
SBOAI_LP_MUFG_MOC リポジトリの index.html のカオスマップを差し替えてください。

<div class="ipabar"> から <p class="cmaplg"> までのブロックを、以下に置き換える。

（ここに生成物を貼り付け）

【差し替え後の確認】
1. 93項目すべてが残っていること（削除・要約されていないか）
2. ●印（直近1年の事例あり）42項目が維持され、title属性の事案名も残っていること
3. 色がすべて var(--...) 参照になっていること（リテラルの色が残っていないか）
   ただし濃紺の塊の上に置く白系文字のリテラルは可
4. 外部リソースの読み込みが増えていないこと（Google Fonts以外は不可）
5. タグの閉じ忘れがないこと
6. ライト／ダーク両テーマで文字が背景に溶けていないこと
7. 狭い画面でページ全体が横スクロールしないこと
8. 使われなくなったCSSクラスを削除すること
```
