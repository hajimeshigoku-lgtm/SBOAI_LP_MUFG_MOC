# SBOAI_LP_MUFG_MOC

SB OAI Japan「Patching as a Service」向け、**業界別 AIサイバーセキュリティ・レポート／メガバンク編**のモック。

LPおよびホワイトペーパー（ダウンロード資料）の構成検証用に作成した、単一HTMLのレポートです。

## 内容

`index.html` の1ファイルで完結します（外部依存はGoogle Fontsのみ）。

| 章 | 内容 |
|---|---|
| SUMMARY | 本レポートの結論（3点） |
| 第1章［共通］ | フロンティアAIが変えたサイバーセキュリティの前提 |
| 第2章［業界個別］ | メガバンクのシステム5層構成とリスクマッピング／固有の3条件（入口・本体・出口） |
| 第3章 | 5つのリスク詳細（なぜ顕在化したか／実際に起きたこと／講じるべき対策） |
| 第4章 | 診断対象の選定軸と進め方 |
| 第5章 | PaaS訴求・価格・データ取扱い・申込CTA |
| APPENDIX | 出典・注記 |

## 構成の出典

- レポートの型：`セキュリティレポートの構成メモ`（共通パート → 構成図上のリスクマッピング → リスクごとに3点セット → PaaS訴求＋申込ボタン）
- システム5層構成：`15業界_システム構成図` の金融セクションを、メガバンク向けに補正（共同センター依存を外し、自前勘定系・グループ横断・SWIFT等の対外接続を追加）
- サービス仕様・価格・免責：`[0727最新]PaaS_初回ご説明資料`

## 実装メモ

- 単一HTML。CSSは`:root`のトークンで管理し、ライト／ダーク両テーマに対応（`prefers-color-scheme`と`data-theme`の両方）
- 図版はインラインSVG。テーマトークンを参照するため両テーマで追従する
- CTAリンクはPaaS公式申込サイトへ接続
